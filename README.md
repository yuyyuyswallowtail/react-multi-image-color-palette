# Color Palette Extractor

Sebuah aplikasi web modern dan minimalist yang memungkinkan pengguna untuk menentukan **color palette** dari gambar yang diupload. Website ini dirancang dengan **React JS, TypeScript, TailwindCSS, Vite, Redux, dan Shadcn UI** agar responsif, cepat, dan user-friendly.

## Fitur Utama

- Upload multiple gambar (JPG, JPEG, PNG, WEBP).
- Menyimpan dan menghapus sementara color palette dari gambar yang diupload.
- Memilih bagian gambar secara manual atau otomatis untuk mengekstrak warna.
- Shuffle color palette sesuai gambar.
- Rekomendasi warna berbasis algoritma untuk palette yang optimal.
- Color picker interaktif yang menempel di atas gambar (tidak keluar dari area gambar).
- Notifikasi saat gambar berhasil diupload dan saat warna berhasil dicopy (dengan kode HEX).
- SEO friendly dan mudah digunakan.

## Teknologi yang Digunakan

- **React JS**
- **TypeScript**
- **TailwindCSS**
- **Vite**
- **Redux Toolkit**
- **Shadcn UI**
- **Library pendukung** (misal: `react-colorful` untuk color picker, `color-thief` atau `fast-average-color` untuk ekstraksi palette)
